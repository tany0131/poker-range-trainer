はじめての人へ — ポーカーを知らなくても大丈夫

このアプリで何をするのか

ひとことで言うと、手札2枚を見て「参加するか、降りるか」を決める練習です。 ポーカーの1回の勝負は4段階ありますが、このアプリが扱うのはいちばん最初の段階だけ (手札2枚が配られて、まだ場にカードが1枚も出ていない状態)。

ここが一番大事です。最初の判断を間違えると、その後どれだけ上手く打っても取り返せません。 逆に言えば、ここだけ覚えれば初心者を一段抜け出せます。

あなたが選ぶのは3つだけ

選択肢意味
フォールド降りる。この回はもう参加しない。損も出ない (すでに出した分を除く)
コール相手と同じ額を払って、付いていく
レイズ / 3ベット相手より高い額を出して、上から被せる

降りるのは負けではありません。 勝てない手で参加しないのが、一番確実に勝ちを増やす方法です。 実際、正解の大半は「降りる」です。

手札の書き方

強い順に A K Q J T 9 8 7 6 5 4 3 2。T は 10 のことです。

表記意味
777 が2枚 (ペア)
AKsA と K で、マークがそろっている (s = suited)
AKoA と K で、マークが違う (o = offsuit)

マークがそろっているだけで、手はぐっと強くなります。 同じマーク5枚を集める「フラッシュ」という強い役を狙えるからです。 このアプリで一番効く一言が 「マークがそろっているかを最初に見る」。

席 (ポジション) がすべてを決める

6人で座っていて、話す順番が決まっています。 UTG → HJ → CO → BTN → SB → BB の順で、UTG が最初、BB が最後。 この席は1回ごとに1つずつずれていくので、毎回変わります。

なぜ席が大事か。 UTG で参加すると、まだうしろに5人も残っています。 その誰かが強い手を持っているかもしれない。だからよほど強い手しか出せません。 BTN ならうしろは2人だけなので、そこそこの手でも出せます。

つまり 同じ手でも、席によって答えが変わります。これがプリフロップの本質で、 このアプリが練習させたいことのほぼ全部です。

まず何をすればいい？

  1. 右下の「説明」ボタンで やさしく を選ぶ (専門用語なしの解説になります)
  2. RFI モードで、まず 30 問くらい適当に答えてみる。間違えて構いません
  3. 間違えると「なぜ」と「覚え方」が出るので、それだけ読む
  4. 慣れてきたら 境界特訓 へ。ここが本当に覚える価値のある 54 ハンドです

バリューかブラフか — 3ベットの役割クイズ

同じ「3ベット」でも役割は2つあります。バリュー = 呼ばれても勝ちにいける手で、ポットを育てる。 ブラフ = 降ろすのが主目的で、呼ばれた時のための保険 (ブロッカーや化け筋) を持つ手。 どちらのつもりで打つかを当ててください。

勝率 ≠ 期待値 — ここが分かると一段上がる

期待値 = 勝率 × 勝ったとき取れる額 − 負率 × 負けたとき払う額。 勝率はその一部でしかありません。レンジ表と見比べると、食い違う場所があります:

勝率が上の K7o が捨てられ、勝率が下の 76s が開けられる。 これが「期待値は勝率だけでは決まらない」の実例です。効くのは (1) ドミネート — 勝ったとき小さく負けたとき大きい形は勝率の数字より弱い、 (2) 化けやすさ — そろい・つながりは勝つときに大きく取れるので勝率の数字より強い、 (3) 位置 — 後に動けるほど勝率どおりに取りやすい、の 3 つ。 レンジ表はこの全部を織り込み済みの答えなので、迷ったらレンジ表に従えば期待値の計算は要りません。

解説 — ポジションと 3ベット

ポジション = 行動する順番

席は行動順に UTG → HJ → CO → BTN → SB → BB と並びます。SB と BB は強制ベット (ブラインド) を出す席。 ボタンは1ハンドごとに1つ左へ回るので、自分のポジションは毎ハンド変わります。

なぜ順番がそこまで効くのか

理由1: 後ろに何人残っているか。 UTG で参加すると、まだ後ろに5人います。その誰かが AA を持っているかもしれない。BTN なら後ろは2人だけ。 後ろの人数が少ないほど、自分の手が一番強い確率が上がる。だから前の席ほど手を絞ります。

理由2: フロップ以降、ボタンが必ず最後に動く。 最後に動けるということは、全員の行動を見てから自分の行動を決められるということ。 最初に動く人は何の情報もなく決めるしかない。この差が毎ラウンド積み上がります。

各ポジションの RFI レンジ

ポジション 性格 開く割合

SB だけがねじれている

SB はプリフロップでは遅い (有利) のに、フロップ以降は最初に動く (最悪) という席です。 後ろに BB しかいないので広く開けますが、その後がずっと不利。 レイズサイズが SB だけ 3bb (他は 2.5bb) なのは、すでにブラインドを出している分 BB が安く見に来られてしまうので、少し高く払わせるためです。

そしてレイズされた側に回ったとき、SB は常に 3ベットかフォールドの二択になります (コールを作らない)。 OOP な上に BB がまだ後ろに残っているので、安く見に行くと2人相手に不利な位置で戦うことになるからです。

BB の進め方 — 手ではなくレイザーから見る

BB で迷う人の多くは、カードを先に見て「この手は強いか？」から入ります。順番が逆です。 先にレイザーの席を見る。相手が UTG なら相手は強い手しか持っていないので狭く (約27%)、 BTN なら相手は半分近くゴミ手なので広く (約半分) 戦えます。同じ手でも相手次第で答えが変わる。

  1. 誰のレイズか — 後ろの席ほど広く戦える
  2. 3ベットの手か — 強い手 + ホイールエース系のブラフ枠
  3. コールの手か — 追加 1.5bb で 5.5bb を狙える (27% で元が取れる)。そろい・つながり・ペアは広く
  4. どれでもなければ降りる — 「もう 1bb 払った」は理由にならない

コールした後の心構えもひとつだけ: BB のコールレンジは弱い手が多いぶん、 フロップで何も当たらなかったら素直に降りるのが基本です。 プリフロップで安く見た分を、当たらなかったフロップで取り返そうとしない。

BB が広く守れる理由

BB はすでにブラインドを払い込んでいるので、コールに必要な追加額が他の席より小さい。 さらに最後に行動してその周を閉じられるので、後ろから殴られる心配もない。 この2つのおかげで、BB は他の席なら降りる手でも守れます。

相手が後ろの席から開けるほど相手のレンジは弱いので、BB のディフェンスも広がります。 UTG のオープンには約27%しか抵抗しませんが、BTN のオープンには約半分の手で抵抗します。

覚え方 — 169個を覚えようとしない

ペアは全席で全部レイズ。 22+ が5席とも共通なので、13ハンドは思考ゼロ。

スーテッドエース (Axs) は UTG 以外すべてレイズ。 HJ 以降は A2s まで無条件。例外は UTG だけで、そこは A9s 以上 + A5s / A4s / A3s。これで12ハンド片付く。

残るスーテッドは「キッカーをどこまで下げられるか」の数字だけ覚える。 丸暗記ではなく形で捉える: UTG は全部9前後、HJ と CO は8前後、BTN と SB は下まで落とす。

UTG はオフスーツをほぼ捨てている (AJo 以上と KQo だけ)。 BTN になると急に Q9o や J9o まで開ける。オフスーツは「後ろの人数が減って初めて許される手」です。

一番効く一言は 「スーテッドは2〜3席ぶん格上げ」。 J9s は UTG から開けるのに、J9o は BTN まで待たないと開けられない。 同じ J9 でも、スート1つで3席ぶん違う。迷ったらまずスーテッドかどうかを確認する癖をつけると事故が減ります。

3ベット側の覚え方 — 構造で絞る

まず席で絞る: コールが存在するのは BTN と BB だけ。 HJ / CO は後ろに人が残りすぎるのでコールドコールせず、3ベットかフォールドの二択。SB も常に二択。 つまり BTN と BB 以外では「コール」ボタンのことを忘れていい。

3ベットレンジは「バリュー + ホイールエース」の2階建て。 柱は 99+ / AQ 級の明確に強い手。そこに A5s〜A2s あたりのスーテッドエースをブラフとして混ぜる。 A を1枚ブロックするので相手の AA / AK が減り、コールされてもフラッシュやホイール (A-2-3-4-5) が残るからです。 全 14 スポットの 3ベットレンジに、このホイールエースが必ず入っています。

最大の罠はオフスーツのブロードウェイ。 KJo / QJo / KTo は見た目より弱く、レイザーの AK / AQ / KQ にドミネートされています (トップペアを作っても相手が上)。「絵札2枚だから」でコールしない。 スーテッドなら守れる手も、オフスーツなら降りるのが基本形。

BB だけは別ルール。 すでに 1bb 払っていて追加が安く、最後に行動してその周を閉じられるので、他の席なら降りる手でも広く守る。 レイザーが後ろの席になるほど守る範囲も広がる (vs UTG 約27% → vs BTN 約半分)。

迷ったら「レイザーがどこか」を最初に見る。 同じ手・同じ席でも、UTG のレイズには降りて BTN のレイズには守る、が普通に起きます。 自分の手の強さ単体ではなく、相手のオープンレンジとの比較で決まるからです。

bb って結局いくらなのか

bb = ビッグブラインド1個ぶんの額を「1」とした単位です。 金額そのもので言うとレートが変わるたびに話が通じなくなるので、ポーカーでは常に bb で数えます。 1bb が 10円のテーブルなら 7.5bb = 75円。1bb が 100円なら 750円。どちらも同じ「7.5bb」です。

このアプリは全スポット 100bb スタート (持ち金 = 100bb) なので、 bb の数字はそのまま「持ち金の何パーセントか」だと思って構いません。

額それは何か持ち金 100bb の1bb=10円なら

卓には手が始まった時点で 1.5bb (SB 0.5 + BB 1) が落ちています。 誰かが 2.5bb 開けた時点でポットは 4bb。 「7.5bb に 3ベット」= 4bb 入っているポットを取りに、7.5bb 出すということです。 出題画面のテーブル図には常にポットが出ているので、そこと見比べてください。

ひとつ注意。ブラインドはすでに払い込んでいるので、その席では差額しか出しません。 BB が 10bb に 3ベットするなら、すでに出している 1bb に 9bb 足すだけ。 サイズの選択肢に「追加 ◯bb」と出ているのがこれです。

3ベットレンジは「強さの順」ではない (ポラライズド)

レンジ表を見ると必ず引っかかる場所があります。CO のレイズに BTN が守るとき、 AQo はコールなのに、格下の AJo が 3ベット。逆転しているように見えますが、これが正解です。

3ベットレンジは強い順に上から取るのではなく、バリューとブラフの両端を取って、真ん中をコールに残す形 (ポラライズド) になっています。

手答え役割
AKo3ベットバリュー (上端)
AQoコール真ん中 — 3ベットが一番もったいない
AJo / ATo3ベットブラフ (下端・ブロッカー)

AQo を 3ベットすると損。 相手が続けてくるのは AK・QQ+ ばかりで、こちらが劣勢。 そして AQo が勝っている KJ・QT・弱い Ax は全部降りてしまう。 強い相手だけ残して弱い相手を追い出す、最悪の使い方です。コールなら弱い手を卓に残したまま、ポジションで殴れます。

AJo はコールでは分が悪い。 A や J でトップペアを作っても、相手の AQ・AK にドミネートされて キッカー負けしがち。ところがブロッカーとしては最良で、A が相手の AA / AK / AQ を、 J が JJ / AJ / KJ を減らします。つまり「4ベットしてくる手」をピンポイントで削れる。 だから「コールには弱すぎるが、ブラフとしては最良」の枠に回ります。

強さではなく役割の問題だと分かれば、同じ形がスーテッドにもあることに気づきます。 CO→BTN では AJs・ATs・A9s がコールで、その下の A8s・A7s・A6s と A4s・A3s が 3ベット。同じバーベル型です。

ついでに覚えておくと強い事実: BTN のコールレンジに入るオフスーツは AQo ただ1つ (UTG / HJ / CO のどのレイズに対しても)。BTN がフラットすると後ろの SB / BB にスクイーズされるので、 フラットは本当に強い手だけに絞るためです。BB のコールレンジには AJo も KJo も QTo も入るのと対照的で、 同じ「コール」でも席が違えば意味が違う好例になっています。

ブラフの考え方 — なぜ弱い手で上乗せするのか

バリューだけで 3ベットしていると、強い手が稼げなくなります。 AA のときだけレイズする人に、相手は絶対に払いません。 ブラフが混ざっているからこそ「今回もブラフかも」と思わせて、本物の強い手に払ってもらえる。 ブラフは嘘というより、バリューの取り立て役です。

良いブラフ候補の3条件。 ① コールでは分が悪い (= バリューの手をブラフに回すのはもったいない)。 ② ブロッカーがある — 自分がその札を持っているだけで、相手が続けてくる強い手の組み合わせが減る。 ③ 呼ばれても化け筋がある — フラッシュやストレートに育つ余地。 この3つを全部満たす代表がホイールエース (A5s〜A2s) で、 だから全スポットの 3ベットレンジに必ず入っています。

やってはいけないブラフが2つ。 AQo のような「コールで十分戦える手」をブラフに使う — これは役割の無駄づかい。 そして 72o のような完全なゴミで打つ — 呼ばれた瞬間に何の保険もない。 ブラフは「捨てるには惜しいが、コールはできない」中間の手から選びます。

そして一番大事なこと: プリフロップのブラフは、その場の気分でやるものではありません。 どの手がブラフ枠かはレンジ表に最初から書いてあります。決められた手で、決められた額で打つだけ。 「読まれたかな」「取り返したいな」でブラフを増やした瞬間に、搾取される側に回ります。

ベットサイズの覚え方 — 手ではなく位置で決まる

サイズはレンジと違って「どの手か」に依存しません。AA でも A5s でも同じ額で打つ。 強い手のときだけ大きく打っていたら、額を見ただけで手の強さが読まれてしまうからです。 だから覚えるのはスポットごとに1つの数字だけ。サイズモードでカードを配らないのはこの理由です。

オープンは 2.5bb。例外は SB の 3bb だけ。 SB が大きいのは、BB がすでに 1bb 出していて安く見に来られてしまうから。少し高く払わせます。

3ベットはオープン額の「IP 3x / OOP 4x」。

状況倍率2.5bb オープンなら
IP (HJ / CO / BTN)3x7.5bb
OOP (SB / BB)4x10bb

なぜ OOP ほど大きいのか。 位置が悪いとフロップ以降で毎ラウンド先に動かされ、勝率どおりにポットを取れません (= エクイティを実現しづらい)。だから降ろす確率を上げ、それでも付いてくる相手には高く払わせる。 逆に IP は安くして、弱い手に付いてきてもらったほうが儲かります。 SB が特に大きいのは、後ろに BB がまだ残っているので、安いと2人相手に最悪の位置で戦うことになるからです。

間にコーラーがいたら1人につき +1bb 足す、が定番の調整。 4ベットは 3ベット額の IP 2.2x / OOP 2.5x 前後ですが、 100bb だとその時点でスタックの1/4が入るので、実質「最後までいく手」しか作れません。

境界特訓モードとは

169 ハンドのうち、大半は考える必要がありません。AA はどこからでもレイズ、72o はどこからでもフォールド。 本当に知識が要るのは「ポジションによって答えが変わるハンド」だけです。 RFI では ハンドがそれに該当し、境界特訓モードはそこだけを一様に出題します。

マトリクスの読み方

答えたあとに出る 13×13 の表は、ポーカーの標準的な書き方です。 左上から右下への対角線がポケットペア、その右上がスーテッド (同じスート = s)、 左下がオフスーツ (違うスート = o)。色は下の凡例のとおりで、黄色い枠が今出題されたハンドです。

combos の話

同じ AK でも、スーテッドは4通り、オフスーツは12通りの組み合わせがあります (スートの選び方の数)。ペアは6通り。 つまり実戦では AKo の方が AKs より3倍よく出る。 境界特訓以外のモードはその頻度どおりに出題しています。均等に出すとペアばかり来て練習になりません。

レンジの出どころ

RFI は公開されている 6-max 100bb のチャート、vs RFI (3ベット) は GTO ソルバー由来のチャートを機械的に抽出し、 別ソースと突き合わせて検算したものです。 ソルバーが混合戦略を取るハンドは、頻度の高い方の action に丸めてあります (1ハンド1答にするため)。 そのぶん境界の細部は本来より少し堅く、そこは「流派の差」の範囲です。

サイズの基準は 25% = 4択を当てずっぽうで押したときの正解率。覚えるのは 「オープン 2.5bb (SB だけ 3bb)」と「3ベットは IP 3x / OOP 4x」の2本だけなので、ここは 100% を狙えます。

行をタップすると、その状況だけを狙い撃ちで練習できます。弱点を潰すときに使う。

基準 = その状況で「降りるべき手」の割合。 何も考えずフォールドを押すだけでこの近辺は取れてしまうので、ここを超えて初めて学習が起きている。 (実際にフォールド連打すると、ミスした手が復習キューで返ってくるぶん基準より下がります。) 目標は各状況 95% (緑)。赤は基準割れ。
