解説 — ポジションと 3ベット

ポジション = 行動する順番

席は行動順に UTG → HJ → CO → BTN → SB → BB と並びます。SB と BB は強制ベット (ブラインド) を出す席。 ボタンは1ハンドごとに1つ左へ回るので、自分のポジションは毎ハンド変わります。

なぜ順番がそこまで効くのか

理由1: 後ろに何人残っているか。 UTG で参加すると、まだ後ろに5人います。その誰かが AA を持っているかもしれない。BTN なら後ろは2人だけ。 後ろの人数が少ないほど、自分の手が一番強い確率が上がる。だから前の席ほど手を絞ります。

理由2: フロップ以降、ボタンが必ず最後に動く。 最後に動けるということは、全員の行動を見てから自分の行動を決められるということ。 最初に動く人は何の情報もなく決めるしかない。この差が毎ラウンド積み上がります。

各ポジションの RFI レンジ

ポジション 性格 開く割合

SB だけがねじれている

SB はプリフロップでは遅い (有利) のに、フロップ以降は最初に動く (最悪) という席です。 後ろに BB しかいないので広く開けますが、その後がずっと不利。 レイズサイズが SB だけ 3bb (他は 2.5bb) なのは、すでにブラインドを出している分 BB が安く見に来られてしまうので、少し高く払わせるためです。

そしてレイズされた側に回ったとき、SB は常に 3ベットかフォールドの二択になります (コールを作らない)。 OOP な上に BB がまだ後ろに残っているので、安く見に行くと2人相手に不利な位置で戦うことになるからです。

BB が広く守れる理由

BB はすでにブラインドを払い込んでいるので、コールに必要な追加額が他の席より小さい。 さらに最後に行動してその周を閉じられるので、後ろから殴られる心配もない。 この2つのおかげで、BB は他の席なら降りる手でも守れます。

相手が後ろの席から開けるほど相手のレンジは弱いので、BB のディフェンスも広がります。 UTG のオープンには約27%しか抵抗しませんが、BTN のオープンには約半分の手で抵抗します。

覚え方 — 169個を覚えようとしない

ペアは全席で全部レイズ。 22+ が5席とも共通なので、13ハンドは思考ゼロ。

スーテッドエース (Axs) は UTG 以外すべてレイズ。 HJ 以降は A2s まで無条件。例外は UTG だけで、そこは A9s 以上 + A5s / A4s / A3s。これで12ハンド片付く。

残るスーテッドは「キッカーをどこまで下げられるか」の数字だけ覚える。 丸暗記ではなく形で捉える: UTG は全部9前後、HJ と CO は8前後、BTN と SB は下まで落とす。

UTG はオフスーツをほぼ捨てている (AJo 以上と KQo だけ)。 BTN になると急に Q9o や J9o まで開ける。オフスーツは「後ろの人数が減って初めて許される手」です。

一番効く一言は 「スーテッドは2〜3席ぶん格上げ」。 J9s は UTG から開けるのに、J9o は BTN まで待たないと開けられない。 同じ J9 でも、スート1つで3席ぶん違う。迷ったらまずスーテッドかどうかを確認する癖をつけると事故が減ります。

境界特訓モードとは

169 ハンドのうち、大半は考える必要がありません。AA はどこからでもレイズ、72o はどこからでもフォールド。 本当に知識が要るのは「ポジションによって答えが変わるハンド」だけです。 RFI では ハンドがそれに該当し、境界特訓モードはそこだけを一様に出題します。

マトリクスの読み方

答えたあとに出る 13×13 の表は、ポーカーの標準的な書き方です。 左上から右下への対角線がポケットペア、その右上がスーテッド (同じスート = s)、 左下がオフスーツ (違うスート = o)。色は下の凡例のとおりで、黄色い枠が今出題されたハンドです。

combos の話

同じ AK でも、スーテッドは4通り、オフスーツは12通りの組み合わせがあります (スートの選び方の数)。ペアは6通り。 つまり実戦では AKo の方が AKs より3倍よく出る。 境界特訓以外のモードはその頻度どおりに出題しています。均等に出すとペアばかり来て練習になりません。

レンジの出どころ

RFI は公開されている 6-max 100bb のチャート、vs RFI (3ベット) は GTO ソルバー由来のチャートを機械的に抽出し、 別ソースと突き合わせて検算したものです。 ソルバーが混合戦略を取るハンドは、頻度の高い方の action に丸めてあります (1ハンド1答にするため)。 そのぶん境界の細部は本来より少し堅く、そこは「流派の差」の範囲です。
